# FrisTracker - Track YOur Games. Solve Conflicts. Optimise your strategies.

Fristracker is an Frisbee Tracking device, supporting Live GPS data transmitting.

## The Idea

This Hadeware projekt aims to connect an microcontroller (ESP32 PICO v3 02) with GPS using an Neo 6M Chip and sending the computed data to 
an Laptop using the onboard NRF24L01+PA+LNA. 
On the Laptop side there is an receiver module. 

## The Goal

The Goal of this projekt is to help Track movement of an flying frisbee during an Game of Ultimate Frisbee - To see what paths were most of the time used, where weak points in the defense were, and just because thats cool.
